# bracecron

Brace validation gates for cron inputs before they hit prod.

**Site:** https://theworker02.github.io/bracecron/

## Install / run

```bash
git clone https://github.com/theworker02/bracecron.git
cd bracecron
node src/cli.js
node --test
```
